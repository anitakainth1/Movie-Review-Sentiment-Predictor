# Movie-Review-Sentiment-Predictor
A deep learning-based sentiment analysis model that classifies movie reviews as positive or negative using LSTM networks trained on the IMDb dataset.

## 🚀 Features
- Uses IMDb dataset for training and testing  
- Implements LSTM-based deep learning model  
- Converts text into numerical sequences using padding  
- Handles sequential text data efficiently  
- Predicts sentiment of custom user input  
- Visualizes training accuracy and loss graphs  

---

## 🛠️ Tech Stack
- Python  
- TensorFlow / Keras  
- LSTM (Deep Learning)  
- NumPy  
- Matplotlib
